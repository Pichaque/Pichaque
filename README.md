## 🤖 Desarrollo con IA y Vibe Coding

También utilizo herramientas de inteligencia artificial para acelerar el desarrollo, explorar soluciones y convertir ideas en prototipos funcionales.

- **OpenCode:** asistencia al desarrollo, generación de código y trabajo con agentes de IA.
- **Vibe coding:** creación e iteración de proyectos mediante instrucciones en lenguaje natural, revisando y ajustando el código generado.
- **Desarrollo asistido:** utilizo la IA como apoyo para resolver problemas, aprender y mejorar mis proyectos.

Creo que la IA es una herramienta potente cuando se combina con la lógica de programación, la revisión del código y las ganas de seguir aprendiendo.
